# 视频外墙检测：评价与标注标准 V1

编制日期：2026-11-08。状态：范围与九类分类由用户确认；本文其余标注与评价规则为实施建议，待样本试标后冻结。本文不是建筑安全鉴定标准，不给出结构安全等级。

## 1. 已确认的范围与类别

- 外楼梯、门、窗不纳入检测、标注和缺陷统计。
- C 与 M 合并为 C；S 与 P 合并，统一使用 S；白华从 L 独立为 E。
- 保留 B，不新增 J。最终类别为 C、S、T、R、D、V、L、E、B。
- 旧类别、原始模型标签和置信分数须保留，规范化业务标签不得覆盖原始输出。

延续当前项目约定：仅评价目标建筑，背景建筑、地面和绿化排除。外楼梯后方属于建筑本身的墙面仍可评价；不可见区域标为不可评价，不当作无缺陷。女儿墙、墙面附属金属件等边界对象应在项目范围清单中逐项确认，不能由智能体临时扩大范围。门窗框、玻璃、门扇及其专属附件随门窗排除；洞口周围建筑墙体不因邻近门窗而自动排除。

## 2. 九类定义、反例和 Mask 规则

| 码 | 类别 | 纳入的可见现象 | 排除或易混淆现象 | Mask 标注对象 |
|---|---|---|---|---|
| C | 裂缝／裂纹 | 不规则线状或网状裂纹；线状/网状为形态字段 | 正常板缝、管线、阴影、反射；划痕无法排除时列观察项 | 实际可见裂纹像素；保留分支与真实间断，不把整块网裂内部填满 |
| S | 剥落／剥损 | 起皮、涂层脱落、抹灰或混凝土表面剥损、饰面材料缺失 | 正常孔洞、设计缺口、反光、单纯色差；不能仅凭黑斑认定剥损 | 可见受损表层、露底或缺失区域；保留其中完好区域 |
| T | 锈色流痕 | 墙面可见锈色流挂或沉积 | 泥水、棕色底材；不能推断内部钢筋锈蚀 | 锈色痕迹实际区域，不自动包含其污染源 |
| R | 可见金属锈蚀 | 范围内外露金属或外露钢筋的可见锈蚀 | 仅有墙面流痕、金属原色；楼梯和门窗金属随对象排除 | 金属上可见锈蚀区域，不填充整根构件 |
| D | 污染／积污 | 积尘、烟熏、一般污渍、可辨识积污 | 正常阴影、底色、裸露基底；明确 T/L/E/V 时优先对应类别 | 污染像素；模糊边界单独标记，不强制纳入整片色差 |
| V | 植生附着 | 目标墙面或墙体缝隙实际附着/生长的植物、苔藓 | 草地、盆栽、树影、遮挡墙面的背景植物 | 墙体附着植生的可见部分，不含周围墙面 |
| L | 水渍／潮湿表征 | 可辨识湿斑、水痕等表征 | 阴影、普通积污、锈色流痕、白华；不据此确诊渗漏 | 水渍/湿斑区域；边界不确定时标为不确定 |
| E | 白华／白色析出物 | 可见白色结晶、粉状或流挂状析出 | 白漆、反光、灰尘、裸露浅色基底 | 析出物区域，不因颜色发白就覆盖全部浅色像素 |
| B | 鼓起／变形 | 有几何证据的隆起、翘曲、局部变形 | 透视、镜头畸变、正常构造；空鼓不能仅凭外观确认 | 可辨识的变形表面范围；边界不足时不强制制作精确真值 Mask |

禁止为了填满类别表而强制分类。无法区分类别时保留 observation + candidate_classes，不将“未知”塞入 D。接缝处发生明确 C/S 等现象时可按其现象分类，但正常接缝是负例；J 不作为输出类别。

## 3. 标注状态与真值资格

分别记录三个独立字段，不混用：

1. scope_status：in_scope / out_of_scope / uncertain。
2. finding_status：candidate / observation / rejected。
3. verification_level：model_only / ai_reviewed / human_image_reviewed / field_confirmed。

AI 复核不是人工复核。人工图像复核也不等于现场确认成因。评测是否采用某条标注由 reference_eligible 另行决定，并附审核人和理由。

明确可见、经独立人工审核的图像现象可作为图像任务参考；需要现场证据才能区分的成因不可冒充真值。scope_status=uncertain 或无可靠类别/边界的区域不进入对应主指标分母，必须报告其数量与覆盖范围。预测落入此区域标为待裁定，不自动奖为正确或判为错误。

先标范围和可评价区域，再标缺陷，不仅审核模型检出的图片；否则不能估计漏检。

## 4. 实例与跨帧去重

- building_id / facade_id / component_id：建筑、立面、构件归属。
- physical_location_id：同一物理部位的跨帧关联。
- instance_id：该位置的一种缺陷现象实例。
- evidence_id：某一帧的证据。每项保留全部关联证据，报告默认展示最清晰代表图。
- 一个位置同时存在裂纹与水渍，可有 C、L 两个实例；统计分别展示位置数和类别实例数。
- 不同视角不能仅凭外观相似强行合并，无法关联时记录 uncertain，交人工裁定。
- 网状裂纹通常按一个连续网络标注，形态记 network；不连通的裂纹是否同实例须按试标规则冻结。
- 同一缺陷重复提交为多个结果不能多得分；主任务应采用缺陷/物理部位级评价，帧级指标作为诊断。

## 5. bbox 与 Mask 的共同规范

- 使用原始解码帧的像素坐标，bbox 为零基 xyxy，右/下边界不包含。
- 检测裁剪、缩放与配准必须保存变换；报告 bbox、Mask 均映射回原帧验证。
- bbox 是可见实例的紧致外接框。上下文留白用于展示，不混入评价用 bbox。
- Mask 为原图尺寸的 0/255 单通道图；不以 bbox 填充替代分割。
- 遮挡后的不可见边界不补画；连接或类别重叠允许独立实例 Mask 重叠，并保留原因。
- 细裂纹不为视觉显眼而加粗真值；叠加图可单独使用显示效果，但不得改变评价 Mask。
- bbox 不足以表示 B 的真实几何量。缺少尺度和标定时，所有类别均不输出物理面积或裂纹宽度。

## 6. 评价指标：先分项，不合成为单一总分

| 维度 | 指标与计算口径 | 真值/证据要求 |
|---|---|---|
| 范围 | 范围误报数：被输出为缺陷、但位于排除对象的预测数 | 冻结的建筑和排除对象标注 |
| 识别 | 类别精确率 TP/(TP+FP)、召回率 TP/(TP+FN)，按类别报告 | 独立标注的正例、负例和可评价区域 |
| 定位 | bbox IoU，以及一对一匹配后的定位通过率 | 人工参考 bbox 与冻结匹配规则 |
| 去重 | 多余重复记录数/预测记录总数；另报真实位置被错误合并的次数 | 物理位置关联真值 |
| 面状 Mask | 类别/实例 Dice、IoU；按 S/T/R/D/V/L/E/B 分开统计 | 独立参考 Mask；B 边界不可靠时不作像素评价 |
| 细线 Mask | C 类像素重叠、中心线覆盖、分支遗漏及连通性 | 独立裂纹标注；容差与骨架算法须冻结 |
| 报告 | 必填项完整率、证据引用一致率、无依据断言数 | 固定模板、来源索引及语义复核 |
| 效率 | 端到端时间、模型调用次数、可获取成本、人工修订耗时 | 实际日志；未知费用/耗时用 null，不填 0 |

匹配建议：先确认建筑/立面，再在同一评价单元内执行类别一致的一对一匹配。IoU 门槛、细线匹配方式和跨帧对应规则在试标后冻结；不能逐次为了提高分数调整。错类预测在类别评价中同时导致预测类别 FP 与真实类别 FN。

Dice=2|预测∩参考|/(|预测|+|参考|)；IoU=|预测∩参考|/|预测∪参考|。参考缺陷非空而预测为空时记 0；不存在正例的类别召回率记 N/A，不记 100%。没有预测时精确率记 N/A，并同时报告 FN。

Mask 质量分两层报告：匹配成功实例上的分割质量，以及将漏检参考实例记零的端到端分割结果。额外误报仍进入检测 FP，不因只算已匹配实例而消失。

## 7. 门槛与优化停止状态

用户尚未批准具体质量阈值，所有 precision/recall/Dice/IoU/细线容差阈值均为 TBD。之前讨论的 95%、90%、0.85 不是已冻结门槛。

建议必须满足的技术条件：来源可追溯、坐标和图片映射正确、未确认项明确标识、报告中不混入排除对象。是否将各项设置为零容忍须在验收配置中确认。

- pass：所有已冻结必达条件通过，必要人工验收完成。
- optimizing：未达标且有具体可验证改动，只重跑受影响环节。
- pending_review：缺少独立真值或存在标注分歧；不能宣称质量达标。
- blocked：素材不可评价、缺少必要输入或达到预算限制；保存检查点，不自动降低门槛。

评价器输出逐项 pass/fail/pending/N/A，不允许执行智能体改阈值。建议连续无改善时请求人工诊断；轮数和预算待确认。

## 8. 第一批试标与数据划分

建议选取约 30–50 张代表性原帧作为试标集，覆盖已出现类别、正常墙面、接缝、阴影、背景、遮挡、门窗及外楼梯负例；数量不是验收阈值。缺少的类别标记未覆盖，后续补样，不生成假真值。

流程：冻结范围清单 → 独立标注 → 对分歧裁定 → 固定标注版本 → 跑一次基线 → 制定可实现的阈值 → 冻结测试集。正式评测样本量再按每类数量、难度和误差不确定性确定。

同一原视频与其剪辑版、相邻帧、同位置近重复画面必须在同一数据分组，避免泄漏。当前同栋建筑用于试标与开发；推广经验应使用独立建筑或采集批次验证。

## 9. 历史结果迁移与当前代码差异

- A01 门板、玻璃线状影像、外楼梯构件异常按范围排除；不能仅按历史编号批量处理，要核对具体构件。
- 外楼梯后墙、洞口周围墙面继续按实际建筑墙体评价。
- 旧 M→C，旧 P→S；旧 L 中有明确白华标签的映射 E，其余 L 不自动改类。
- 当前 taxonomy.py 仍将 P/S 分开，尚无 B，L 的英文名仍为 Leakage。本文仅确定标准，不表示运行时代码已经迁移。
- 下游分割器的旧类别码不能随业务合并直接替换：保留语义子类型和显式适配表，验证后再上线。
- 旧报告不原地改写；重评必须记录标准版本和原始标签，生成新结果。
